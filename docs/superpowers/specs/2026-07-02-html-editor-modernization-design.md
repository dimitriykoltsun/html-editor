# HTML Editor — модернизация до Angular 21 и демо для портфолио

**Дата:** 2026-07-02
**Статус:** утверждено

## Цель

Взять извлечённый из старого проекта (Angular 14, «company») WYSIWYG-модуль `html-editor` и превратить его в самостоятельный демо-проект для портфолио: современный стек (Angular 21, standalone, signals), одна демо-страница с редактором, на которую можно давать ссылку.

## Контекст и ограничения

- Исходник: папки `components/`, `module/`, `pipes/` — Angular 14, NgModule, `ControlValueAccessor`, компонент `HtmlEditorComponent` ~5300 строк.
- Ядро редактирования построено на `contenteditable` + `document.execCommand` (deprecated, но работает во всех браузерах) и генерации HTML-строк с прямой работой с DOM. **Осознанное решение: ядро не переписываем** — модернизируем обвязку.
- Зависимость `SharedMaterialModule` (из старого проекта) отсутствует — заменяется прямыми импортами Angular Material.
- Портфолио живёт отдельно; этот проект — standalone-демка.
- Деплой — вне скоупа этой спеки (решение отложено).
- Git-коммиты выполняет пользователь (правило из глобального CLAUDE.md).

## Стек

| Решение | Выбор | Обоснование |
|---|---|---|
| Angular | 21, standalone | актуальная мажорная версия |
| Change detection | **zone.js, не zoneless** | редактор мутирует состояние из `addEventListener`/`setTimeout`-колбэков; под zoneless UI перестанет обновляться. Zoneless — возможный отдельный этап после стабилизации |
| UI | Angular Material 21 (M3) | старый код уже на MatDialog/иконках; минимум правок шаблона |
| Ресайзы | interactjs (свежий 1.10.x) | оставляем, работает |
| Даты | `Intl.DateTimeFormat` | заменяет moment (нужен только чипам даты/времени) |
| Удаляем | moment, ngx-translate, ng-click-outside, swiper, ng-apexcharts | в модуле не используются либо заменены |

## План модернизации: 4 прохода

После каждого прохода приложение собирается и проходит ручной чек-лист (см. Верификация).

### Проход 0 — «компилируется и работает»
- `ng new` (Angular 21) в корне папки; старый код переезжает в `legacy/`.
- Копия кода в `src/app/editor/`; правка импортов: Material-модули напрямую вместо `SharedMaterialModule`.
- Починка strict-ошибок TypeScript (неинициализированные поля, implicit any).
- `moment` → `Intl.DateTimeFormat`.
- Критерий: редактор открывается, печатает текст, вставляет таблицу.

### Проход 1 — standalone
- Удалить `HtmlEditorModule`; компоненты и пайп → standalone с явными `imports`.
- DI через `inject()`.
- Удаление мёртвого кода, найденного по пути (например, пустая подписка на `queryParams` в `ngOnInit`).

### Проход 2 — шаблон
- `*ngIf`/`*ngFor` → `@if`/`@for`.
- Все inline `onclick="document.execCommand(...)"` из шаблона → методы компонента (единая точка `exec(command, value?)`).

### Проход 3 — signals
- Флаги тулбара (`current*`, `show*`, `selected*`) → `signal()`/`computed()`.
- `@Input`/`@Output` в `PreviewComponent` и `HtmlEditorDialogComponent` → `input()`/`output()`.

## Демо-обвязка

Одна страница без роутинга и бэкенда:
- **Шапка**: название проекта, бейджи технологий (Angular 21, Signals, Material, interactjs), ссылка на GitHub (добавляется, когда появится репозиторий).
- **Редактор**: `<app-html-editor [(ngModel)]="content">` на остальную высоту экрана.
- `content` предзаполнен демо-документом (заголовок, абзацы, таблица, картинка), чтобы возможности были видны сразу.

## Известные риски и решения

- **`writeValue` вызывает `propagateChange`** — нарушение контракта CVA, риск цикла на новых формах. Исправляется на каноничную реализацию (функциональный багфикс, разрешён несмотря на «ядро не трогаем»).
- **Material 13→21**: изменилась DOM-структура и тема; SCSS диалога, вероятно, потребует точечных правок.
- **`document.execCommand` deprecated** — осознанно оставляем; фиксируется в README и CLAUDE.md.
- **`SafeHtmlPipe` обходит санитизацию** — приемлемо для демо без серверных пользовательских данных; отмечается в README.
- **Классы в TS-шаблонных строках ↔ глобальный SCSS** (`ViewEncapsulation.None`): при любых правках имена классов должны оставаться синхронными.

## Верификация

**Ручной чек-лист** (прогоняется в браузере через Playwright после каждого прохода):
1. Набор текста; bold / italic / underline / цвет шрифта и фона.
2. Вставка таблицы через конструктор + ресайз колонок.
3. Layout-колонки (col6 и др.).
4. Вставка картинки по URL + ресайз; вставка YouTube-видео.
5. Chips-поля (Company, DateTime, Email…) перетаскиванием.
6. Header/footer с датой.
7. Preview и возврат из него.
8. Переключение формата A4/A3, portrait/landscape.

**Unit-тесты**: spec-заглушки заменяются минимальными smoke-тестами (компонент создаётся; CVA принимает значение). Покрытие DOM-логики ядра — вне скоупа.

## Definition of Done

- `npm run build` — без ошибок.
- Ручной чек-лист пройден полностью на финальной версии.
- `legacy/` удалена.
- README с описанием, скриншотом и стеком; CLAUDE.md обновлён под новую структуру.

## Вне скоупа

- Замена `document.execCommand` на Selection/Range API.
- Разбиение монолитного компонента на сервисы/подкомпоненты.
- Выделение редактора в публикуемую npm-библиотеку.
- Zoneless change detection.
- Деплой (Firebase Hosting / GitHub Pages — отдельное решение позже).
- Роутинг, бэкенд, сохранение документов.
